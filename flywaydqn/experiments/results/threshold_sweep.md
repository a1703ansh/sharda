# Threshold sensitivity — measured table

Generated by `python -m experiments.run_threshold_sweep`. Every number below
is an aggregate of `experiments/results/threshold_sweep.csv`; the CSV is the
source of truth.

Each policy/scenario/seed pair is rolled once. The exposure threshold does
not change the radio or the policy action in this simulation, so the
throughput, dose, max S, power, and null columns are identical across
thresholds for the same rollout; only `fraction of frames over threshold`
moves. That fraction uses the per-frame peak footprint density.

## Notes

- **No measured frame reaches the lowest sweep threshold (0.1 W/m²).** This is a finding, not a missing column: the modelled peak footprint densities stay below every spec sensitivity point.
- The demo scenarios use their own configurable threshold (0.03 W/m²); the baseline table measures crossings at that threshold.
- The cell-level fraction (`mean_frac_over`) needs the full footprint grid and is not recomputed here; `baselines.csv` carries it at the scenario threshold.
- `null_fraction` is the check on whether the window measured mitigation: if it is 0, the horizon ended before the null engaged.
- Wall-clock time and the exact command are in `threshold_sweep_run.json`, not in the deterministic CSV.

## Command

```
python -m experiments.run_threshold_sweep --horizon 500 --seed-count 10
```
