# Baselines — measured comparison table

Generated by `python -m experiments.run_baselines`. Every number below is
an aggregate of `experiments/results/baselines.csv`, which holds one row per
policy × scenario × seed; the CSV is the source of truth.

Surface: `flywaydqn.demo.runner.DemoRunner` — the same frame producer the
dashboard streams. It applies each policy's action exactly (transmit power
including a shut-down 0 mW, and the transmitted weights), which the
environment's four-point **non-zero** power grid cannot represent.

## Coverage of the spec's baseline list

| baseline | present in this table | what it is |
|---|---|---|
| `unconstrained` | yes | max-throughput SON: greedy beam, full power, no mitigation |
| `static-backoff` | yes | static back-off: fixed power reduction while the flock is in range |
| `sector-shutdown` | yes | sector shutdown: transmitter off while the flock is in range |
| `analytic-nulling` | yes | analytic nulling: closed-form projection null on the peak cell |
| `ppo` | **no** | PPO trained on the same environment |
| `dqn` | yes | trained controller served by the service |

- Horizon: 500 steps advanced per rollout (+1 initial frame), dt = 0.1 s
- Scenarios (3): `scenario_001`, `scenario_002`, `scenario_003`
- Seeds (34): `20000`–`20033`
- Measured rollouts (rows): 510 (5 policies × 3 scenarios × 34 seeds)

## Notes

- Rollouts are paired: every policy sees the same scenario/seed pair, so the comparison is a paired one rather than two independent sample sets.
- `null_fraction` and `mean_null_depth_db` are per-row columns of the CSV; `null_depth_db` is exactly 0 on frames with no null on the air.
- The DQN row is the checkpoint the service serves (`FLYWAYDQN_CHECKPOINT_DIR` overrides it), not a re-trained or re-selected one.
- The CSV excludes wall-clock time so a clean re-run is byte-identical; the run's timing and exact selection are in `baselines_run.json`.
- `null_fraction` is the check on whether a window measured mitigation: if it is 0, the horizon ended before the null engaged and those exposure columns are a no-null result, not a nulling result.
- **Not measured:** `ppo` — not implemented yet, so absent by fact.
